APP 攻防最后一讲，讲微信小程序。两个目的：从小程序里挖资产（域名、API、AK/SK、敏感信息）和对小程序本身测漏洞。思路和 Web 渗透基本一样，区别在入口——PC 微信小程序

## 小程序抓包

两种方式：

1. 系统代理导向 BP：简单但抓所有包，要自己筛
2. 科来 + Proxifier + BP（推荐，精确）：科来看进程名 → Proxifier 配抓包规则 → BP 收包

进程区分：`WeChat.exe` 聊天主程序、`WechatBrowser.exe` 公众号浏览器、`WeChatAppEx.exe` 小程序，可分开抓

## 反编译

**找包文件**：微信设置里看文件存储位置；新版微信（4.1+）缓存在 `C:\Users\用户\AppData\Roaming\Tencent\xwechat\radium\Applet\packages`。只有一个 `__APP__.wxapkg` 是简单架构；一堆 .wxapkg 是主包+分包，复杂架构要全部反编译

**反编译工具**：

- wxappUnpacker（https://github.com/YangChengTeam/wxappUnpacker ，nodejs 环境 npm install；加密包先用 UnpackMiniApp 解密到 wxpack 目录）：

```
node wuWxapkg.js "路径\__APP__.wxapkg"
```

- 小锦哥小工具（https://www.xjgxcx.xiejijin.com/ ，免费，自带解密）
- unveilr（`.\unveilr.exe 文件夹路径`，可整个文件夹批量反编译，适合分包架构）

**看源码**：微信开发者工具导入反编译目录，按目录结构针对性搜（app.js 全局配置、pages 页面、utils 工具类）

## 五个挖掘案例

**1. JWT 越权（EDUSRC）**：抓个人中心报名信息包，请求带 JWT。解码后改 jti 编号重新提交——签名校验形同虚设，遍历 jti 拿到任意用户信息，水平越权

**2. 接口信息泄露（EDUSRC）**：反编译导入开发者工具分析源码，找到用户报修接口能拿大量 openid；拿 openid 调另一个接口获取用户详细信息（含 studentID）；再用 studentID+姓名绑定水卡，可充值/挂失——一条链打穿

**3. 加解密算法还原**：抓包对比搜关键词定位加密代码块 → 跟进调用链（a 方法 → d.fetch → request）→ 找到加密配置：AES/ECB/PKCS7 → 在线站解密成功 → 后续可构造加密 payload 测试

**4. 参数漏洞**：抓包发现 goods_name 参数无加密 → 直接测 payload 疑似 SQL 注入 → 丢 Sqlmap 跑出加密的后台密码 → 再反编译小程序找解密算法登后台（思路）

**5. 云 OSS 泄露**：反编译后直接搜 `ossAccessKeyId` 等敏感词 → 捡到泄露的 AK/SK → OSS 工具连接 → 拖走大量数据

## 要点

小程序测试本质还是 Web 那套：抓包测参数（注入/越权/未授权）、反编译挖配置（AK/SK、接口、硬编码密钥）、加密接口先逆向还原算法再测。关键词搜索是核心动作——抓包对不上就搜密文字段名，找资产就搜 ossAccessKeyId/appid/secret 这类。JWT 改 jti、openid 当参数传、云凭据硬编码，这三个是小程序最常见的问题点
